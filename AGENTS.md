## Agent skills

Issues são rastreadas no GitHub Issues via `gh` CLI (repositório ainda a ser criado). See `docs/agents/issue-tracker.md`.

Etiquetas padrão: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `CONTEXT.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.
